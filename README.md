# Заявление НСЖ — предпросмотр дизайна формы

Статичная (HTML/CSS/JS) копия формы заявления на **накопительное страхование жизни с
участием в прибыли** (продукт SAQTAU / PRO LIFE) — вид «Test view main» из основного
Jmix/Vaadin-приложения. Сделана для **сбора обратной связи по дизайну**: ссылку можно
отправить кому угодно, бэкенд не нужен.

> ⚠️ Это **демонстрация интерфейса**. Введённые данные никуда не отправляются и нигде не
> сохраняются — сабмита нет. Это не рабочее приложение, а копия внешнего вида и поведения формы.

## Что внутри

| Файл | Назначение |
|------|-----------|
| `index.html` | Оболочка страницы |
| `styles.css` | Тема бренда (портирована из `frontend/themes/Document/Document.css`) — зелёный `#47903C`, синий `#2D5171` |
| `app.js` | Вся логика формы: мастер из 5 шагов, условные поля, выгодоприобретатели, плитки заболеваний |
| `icons/` | PNG-иконки заболеваний |

## Форма = 5-шаговый мастер

1. **Страхователь** — блок «удостоверение личности»
2. **Застрахованный** — поля скрыты до выбора застрахованного; кнопка «+ доп. застрахованный»
3. **Страховая защита** — взнос, периодичность, доп. страховые покрытия (7 пунктов)
4. **Выгодоприобретатели** — цветные карточки по типам выплат, доли до 100%
5. **Опросник** — рост/вес, давление, плитки заболеваний, спорт/профессия, блок агента

Воспроизведены: условные раскрытия полей, зеркалирование данных страхователя в застрахованного,
живые пикеры «выбрать выгодоприобретателя», лимит долей 100% на тип выплаты, эксклюзивная плитка «Нет».

## Запуск локально

Любой статический сервер, например:

```bash
python3 -m http.server 8090
# затем открыть http://localhost:8090
```

## Синхронизация с реальной формой

Это **отдельная копия** дизайна. Когда меняется `TestViewMain` в основном проекте, соответствующие
правки переносятся сюда (`app.js` / `styles.css`), после чего:

```bash
git add -A && git commit -m "sync: <что изменилось>" && git push
```

GitHub Pages пересобирает сайт автоматически (обычно за ~1 минуту), и все, у кого есть ссылка,
видят обновление.
