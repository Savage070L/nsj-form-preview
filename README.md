# Заявление НСЖ — предпросмотр формы (на компонентах Vaadin)

Статичная копия формы заявления на **накопительное страхование жизни с участием в прибыли**
(продукт SAQTAU / PRO LIFE) — вид «Test view main» из основного Jmix/Vaadin-приложения.
Собрана на **тех же самых компонентах Vaadin 24.9** и с **той же темой `Document.css`**, что и
приложение, поэтому выглядит 1:1. Нужна для **сбора обратной связи по дизайну**: ссылку можно
отправить кому угодно, бэкенд не нужен.

**Живая версия:** https://savage070l.github.io/nsj-form-preview/

> ⚠️ Это **демонстрация интерфейса**. Введённые данные никуда не отправляются и нигде не
> сохраняются — сабмита нет.

## Стек

- **Vite** собирает статику из компонентов Vaadin.
- `main.js` — вся форма и логика (5-шаговый мастер, условные поля, выгодоприобретатели,
  плитки заболеваний), построенная на реальных `vaadin-*` компонентах.
- `Document.css` — **точная копия темы** из `frontend/themes/Document/Document.css`.
- `theme-extra.css` — мелкие служебные стили (утилиты отступов, шаги мастера).
- `icons/` — PNG-иконки заболеваний (бандлятся Vite).

## Форма = 5-шаговый мастер

1. **Страхователь** — блок «удостоверение личности»
2. **Застрахованный** — поля скрыты до выбора застрахованного; кнопка «+ доп. застрахованный»
3. **Страховая защита** — взнос, периодичность, доп. страховые покрытия (7 пунктов)
4. **Выгодоприобретатели** — цветные карточки по типам выплат, доли до 100%
5. **Опросник** — рост/вес, давление, плитки заболеваний, спорт/профессия, блок агента

## Разработка

```bash
npm install
npm run dev      # локальный дев-сервер Vite
npm run build    # сборка в dist/
```

## Деплой и синхронизация

Пуш в ветку `main` запускает GitHub Action (`.github/workflows/deploy.yml`), который собирает
проект (`npm ci && npm run build`) и публикует `dist/` на GitHub Pages — автоматически, за ~1–2
минуты.

Это **отдельная копия** дизайна: когда меняется `TestViewMain` в основном проекте, правку
переносят сюда (`main.js` / `Document.css`) и пушат:

```bash
git add -A && git commit -m "sync: <что изменилось>" && git push
```
